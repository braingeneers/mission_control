## Config / CLI
| Configuration / CLI and meaning |
| --- |
| Env NRP_MONITOR_S3_ENDPOINT: custom S3 endpoint URL override (default state.DEFAULT_S3). |
| Env NRP_MONITOR_S3_INCLUSTER: controls in-cluster fallback job (auto or off). |
| Constants S3_JOB_WAIT_S (120s) and S3_JOB_POLL_S (2s) for polling in-cluster check Job. |

## Data Shapes
- s3_split(uri) return: (bucket, key) tuple for valid object URIs, or None for invalid/directory URIs.
- s3_exists return: True (exists), False (404 Not Found), or None (error/unverifiable).
- S3 prepass cache in state.S3_PASS: {uri: bool}.

## Notes
- Uses aws s3api head-object instead of aws s3 ls to prevent prefix matching bugs (e.g., DONE matching DONE.1).
- Fail-closed: returns None on errors/timeouts/403s; callers never treat None as success.
- Runs at most one short in-cluster Kubernetes Job per monitor pass (incluster_job) to check S3 keys when external access from laptop fails.
- Preserves last 200 lines of pod and job logs in <task>/logs/<stage>.txt before deleting pods.
